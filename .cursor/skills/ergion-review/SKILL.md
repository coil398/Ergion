# Ergion のページの確認

ページを完成と呼ぶ前に、確認する人はこの手順をすべて行います。書く側の規則は `.cursor/skills/ergion-implement/SKILL.md` です。

## 1. 変えたページを開く

差分を読むだけの確認は、確認ではありません。変えたページを、幅 1440px と 390px、明るい配色と暗い配色で開きます。

## 2. 語を一つずつ書き出す

- 見出しの隅の語（corner chip、`quiet-label`）、式の下の注記（`equation-note`）、ボタンの文字を、ページごとにすべて書き出します。
- 次の語が画面にあれば不合格です: つながり、確認済、隅の語としての厳密解、換算単位、隅の語としての有理数、公開の前、式を満たす関数、配色、明るい、暗い、端末、暗くする、明るくする、誤差は実線、計算時間、CLI。
- 読者が意味を尋ねる語は不合格です。終端時刻は \(t = \Delta t \times\) ステップ数なので、`t = 10.00` のようにその量で書くこと。時間刻みとステップ数はフィールドの名前として残します。
- ボタン、見出し、または次の段落を言い直すだけの文は不合格です。「変更した条件は、適用後の新しい計算に使います。」も、CLI の文も不合格です。ページに、読者のための CLI はありません。見出しの末尾の装飾のドット、見出しを繰り返すだけの文（「力学では」）、項目が「ページでは〜を見ます」と書くだけの文、節のページ数を数える結びの文（「力学のページは〜八つです」）は不合格です。数式は残します。
- 隅の語と注記は、見出しにない具体的な事実（例: \(f(x) = x^2 - 2\)）だけが合格です。見出しを言い換える語、分類を名付ける語は不合格です。見出しの右に式のカード（`.intro .equation`）があれば不合格です。
- 配色の切り替えは、明るいページで月、暗いページで太陽のアイコン一つで、画面に語がないこと。
- +t の文字は +t、終端から同じ数を除くボタンの文字は -t で、+t の隣にあること。再生、一時停止、ループ再生、1ステップは短い語のままであること。操作の名前が文（計算時間を伸ばす、計算時間を延ばす）なら不合格です。
- サンプルが式をライブラリ呼び出しの中に隠す、または CLI に触れるなら不合格です。実行は、その繰り返しの点をコードの下のグラフに描くこと。
- ヘッダーに標語がないこと。文に Rust のパスや型名がないこと。f64、丸め、証明のファイル名についての段落がないこと。

## 3. 中身を確かめる

- 計算のページが、次の領域を一つでも飛ばす、または順を崩すと不合格です。見出しと一文、そのページのグラフの画像（縦横比を保つ。明るい配色と暗い配色）、番号のついた手順（続く式は一つの板）、条件、運動の図と再生（再生、一時停止、ループ再生、+t、-t、1ステップ）、傾きを書いたコード（実行がその点を描く）、手で確かめられる例一つ、関連ページ（リンクだけ）、最後の証明。証明は命題と原文だけであること。
- 力学、微分方程式、証明の一覧は、元のグラフがない目次です。冒頭の図があれば不合格です。これらは計算のページではないので、条件、再生、傾きのコードがないことでは不合格にしません。
- 表示する式の板の行に番号がない、番号が（1）、（2）、（3）の順でない、番号が板の右にない、文の一部にすぎない行中の式に番号が付く、板を指す本文が番号を引いていない、は不合格です。
- 外枠が接している、または一つの式の板の中が外枠と同じ間隔で開いている、は不合格です。枠と枠のあいだにページの地が見えること。
- 手順の代数が飛んでいないこと。行列式から因数分解した多項式へ一足で移るような飛びは不合格です。
- 記号がすべて名付けられていること。画面の数ごとに、厳密か近似かが書いてあること。
- 例が紙と鉛筆で確かめられること。その数がライブラリの返した値として画面に出ること。
- 冒頭の図が画像であること。明るい配色は `figures/<id>/figure.png`、暗い配色は `figures/<id>/figure-dark.png` で、テーマに従って入れ替わること。画像は、表示する大きさで、縦横比を保って描かれていること。540×320 の画像を 720×280 に引き伸ばすことは不合格です。代替テキストは主張の一文で、図の下に説明がないこと。軸があること。曲線の意味が残っていること。言葉のないアイコン、空の軸だけ、ページの id と無関係な枠は不合格です。見出しの右に式のカード、見出しの末尾の装飾のドット、分類の隅の語があれば不合格です。
- 幅 850px 以下では、目次が閉じた一行「目次」から始まり、その一行で開くこと。閉じているときはその一行だけであること。常に開いたスクロール枠は不合格です。広い画面の左の目次はそのままであること。
- ページが式を計算し直していないこと。数はライブラリが返したものであること。
- 関連ページがリンクだけで、二つめの説明文も隅の語もないこと。
- 日本語が `.cursor/skills/ergion-japanese/SKILL.md` に従っていること。

## 4. 記録する

不合格の項目ごとに、ページと行を書きます（例: `studio/src/eigen.ts:42 行列式から因数分解へ飛んでいる`）。すべての項目が合格になるまで、そのページを完成と呼びません。
