# Ergion のページを書く規則

Ergion のページを加えるとき、または変えるときは、この規則に従います。日本語の書き方は `.cursor/skills/ergion-japanese/SKILL.md`、見た目は `.cursor/skills/ergion-design/SKILL.md` と `DESIGN.md` に従います。ページを完成と呼ぶ前に、`.cursor/skills/ergion-review/SKILL.md` の確認を通します。

## 1. ページは、それだけで学べる

各領域は、一つの仕事だけを持ちます。本文は上から次の順です。読む順もこの順です。計算のページがこのうち一つでも飛ばすと、そのページは完成ではありません。

1. 見出しと一文。このページがどの計算かを書きます。見出しの右に式は置きません。見出しの末尾に装飾のドットは置きません。
2. 冒頭の図。見出しと一文のあと、長い導出の前です。そのページのグラフの画像で、明るい配色は `figures/<id>/figure.png`、暗い配色は `figures/<id>/figure-dark.png` です。テーマに従って入れ替えます。画像は、表示する大きさで、縦横比を保って描きます。540×320 の画像を 720×280 に引き伸ばしません。代替テキストは、その図の主張を一文で書きます。図の下に説明は置きません。軸を含みます。言葉のないアイコンにはしません。目次のように元のグラフがないページには置きません。空の軸だけを、ページの id と無関係に出しません。
3. 解法の手順。表示する式の板の各行に、右へ（1）、（2）、（3）と、ページの順に番号を付けます。続く式は一つの板を共有します。本文が板を指すときは、その番号を引きます。「次の式」「上の式」のまま残しません。文の一部にすぎない行中の式には番号を付けません。代数の行をすべて書きます。一行ごとに `eq(...)` で式を置き、行と行のあいだは短い文でつなぎます。
4. 条件。図に入る数です。終端時刻は \(t = \Delta t \times\) ステップ数で、`t = 10.00` のように書きます。
5. 運動の図と再生。再生、一時停止、ループ再生、+t、-t、1ステップです。
6. コード。そのページの右辺について、繰り返し、傾き、更新を書きます。実行は、その繰り返しの点をコードの下のグラフに描きます。
7. 手で確かめられる、数を代入した例を一つ。
8. 関連ページ。リンクだけを並べます。リンクに説明の文を付けません。
9. 証明。本当に証明のある単元だけに置き、ページの最後に置きます。中身は命題と、その原文（Lean のソース、または証明の手順）だけです。

- **目次は計算のページではない**: 力学、微分方程式、証明の一覧は、元のグラフがないので冒頭の図を置きません。条件、再生、傾きのコードを欠いても、上の順の欠落にはしません。
- **狭い画面の目次**: 幅 850px 以下では、閉じた一行「目次」から始まります。その一行で開き、閉じているときはその一行だけです。常に開いたスクロール枠は置きません。広い画面の左の目次はそのままです。
- **外枠の間隔**: 外枠と外枠のあいだには、ページの地が見える帯を置きます。一つの式の板の中は開けません。
- **置かないもの**: ヘッダーの式のカード、見出しの末尾の装飾のドット、分類の隅の語、操作を言い直すだけの文。

- **行を飛ばさない**: 行列式から因数分解した多項式へ一足で移りません。行列式を定義どおりに展開した行、括弧を外した行、同類項をまとめた行、因数分解した行を順に書きます。
  - **飛ばした例**: \(\det(A - \lambda I) = 0\) より \((\lambda - 3)(\lambda + 1) = 0\)。
  - **書く例**: \(\det\begin{pmatrix} 1-\lambda & 1 \\ 4 & 1-\lambda \end{pmatrix} = (1-\lambda)^2 - 4\)、\(= \lambda^2 - 2\lambda - 3\)、\(= (\lambda - 3)(\lambda + 1)\)。
- **記号を名付ける**: 式に出る記号は、最初に出たところで何であるかを書きます。
- **厳密か近似かを言う**: 画面に出す数ごとに、厳密な値か近似の値かを書きます。
- **例は手で確かめられる**: 例の数は、紙と鉛筆で同じ値に至る大きさにします。

## 2. 計算はライブラリが行う

- 新しい計算は `crates/ergion-core` の関数に置き、その式をその関数の rustdoc に書きます。テストで手の例と一致することを確かめます。
- `crates/ergion-lab` がその関数をページへ渡します。図の値は `lesson_figure`、時間とともに進む値は `LessonSimulation` が返します。
- ページはライブラリが返した値だけを描きます。TypeScript で式を計算し直しません。
- 数値解法が選べる単元では、選択は一つの横並びのタブです。選んだ方法の名前をライブラリへ渡します。

## 3. 文言は見出しだけで足りる

- **見出しは単独で立つ**: 見出しの隅の語（corner chip、`quiet-label`）、式の下の注記（`equation-note`）で、見出しを言い換えたり分類を名付けたりしません。
- **量の名前は、その量にする**: 読者が意味を尋ねる語は、その語が実際に指す量に置き換えます。終端時刻は \(t = \Delta t \times\) ステップ数なので、画面には `t = 10.00` と書き、計算時間とは書きません。フィールドの名前は時間刻みとステップ数のままです。
- **言い直しは消す**: ボタン、見出し、または次の段落を言い直すだけの文は置かない。「変更した条件は、適用後の新しい計算に使います。」も、CLI の文も置かない。ページに、読者のための CLI はありません。見出しの末尾の装飾のドットも置きません。見出しを繰り返すだけの文（「力学では」）、項目が「ページでは〜を見ます」と書くだけの文、節のページ数を数える結びの文（「力学のページは〜八つです」）は置かない。数式は残します。
- **残してよい語**: 見出しにない具体的な事実だけです。たとえば例の見出しの隅の \(f(x) = x^2 - 2\) や、式に出る記号の定義 \(\omega = \sqrt{k/m}\) です。迷ったら置きません。
- **画面に出さない語**: つながり、確認済、隅の語としての厳密解、換算単位、隅の語としての有理数、公開の前、式を満たす関数、配色、明るい、暗い、端末、暗くする、明るくする、誤差は実線、計算時間、CLI。
- **配色の切り替え**: ヘッダーの一つのアイコンのボタンです。明るいページでは月、暗いページでは太陽を示し、画面に語を出しません。
- **再生の操作**: 再生、一時停止、ループ再生、+t、-t、1ステップです。+t は現在の終端より先へ、いまのステップ数と同じ数を足します。-t はその同じ数を終端から除きます。文字は `-t` です。どちらも文にはしません。計算時間を伸ばす、計算時間を延ばす、のような文をボタンの名前にしません。
- **コード**: サンプルは、そのページの右辺について、繰り返し、傾き、更新を書きます。ライブラリ呼び出しの中に式を隠したページ、CLI に触れるページは、完成ではありません。実行は、その繰り返しの点をコードの下のグラフに描きます。
- **計器の下の差**: 量ごとに一行です。
- **書かないもの**: ヘッダーの標語。文の中の Rust のパスや型名。f64、丸め、証明のファイル名についての段落。

## 4. 図とテスト

- ページの図は、見出しと一文のあと、長い導出の前に、軸のあるグラフの画像として置きます。明るい配色は `figures/<id>/figure.png`、暗い配色は `figures/<id>/figure-dark.png` で、テーマに従って入れ替えます。画像は、表示する大きさで、縦横比を保って描きます。目次のように元のグラフがないページには置きません。
- 幅 850px 以下の目次は、閉じた一行「目次」から始まります。その一行で開き、閉じているときはその一行だけです。常に開いたスクロール枠は置きません。広い画面の左の目次はそのままです。
- 表示する式の板の各行には右に（1）、（2）、（3）を付け、行中の式には付けません。本文が板を指すときは、その番号を引きます。外枠と外枠のあいだにはページの地が見え、一つの式の板の中は開けません。
- Canvas の色は `figurePalette()` のトークンだけを使い、TypeScript に色の値を書きません。
- テストは、読み順、板の番号、外枠の間隔、図の配色の切り替え、禁止の語がないこと、例の数がライブラリの値として画面に出ることを確かめます。
