# 開発ロードマップ

各段階は実行して結果を確認できる状態で区切る。チェックの完了は実装と検証結果の両方で判断する。カリキュラムは基礎力学、電磁気学、解析力学、微分方程式の順に進む。基礎力学の内部も単純なものから進め、現在の学習単元は一粒子の等速直線運動（$x = x_0 + v t$）であり、これを仕上げる段階である。等加速度運動やNewtonの法則はその後に続き、電磁気学・解析力学・一般ODE章はまだ始めない。式の解説の正本は計算するRust関数の rustdoc であり、画面は動く粒子を示してその関数を参照する。調和振動子のコードは保持されている。公開ホスティングは行わずCursorローカルで閲覧する。

残作業の対象範囲・依存順・完成条件は[Studio初回実装とv0.1残作業計画](plans/studio-oscillator.md)に記録する。

[形式検証計画](plans/formal-verification.md)では、Leanによる数値モデルの証明とTLA+／TLCによるWorker制御の検査を段階的に加える。現在は計画のみで、実行済みの数値テストとは分けて管理する。

## 第2段: 金融で共通コアを実証

最小MDの直後に着手する。MDの大規模化より先に、分野をまたぐ再利用性を検証する。

- 伊藤型SDE、経路ごとの乱数、平均・分散などの統計を導入する。
- 物理側のブラウン運動と、金融側の小さな価格過程を同じ数値基盤に載せる。
- 金融の初期例は幾何ブラウン運動と欧州型オプション評価を候補とし、着手時に確定する。
- 既知の分布・モーメント・価格を用い、離散化誤差とMonte Carlo誤差を分けて検証する。

完了条件: 物理と金融が共通のSDE・乱数・統計を利用し、QuantがMDの粒子や力場に依存していないこと。経路IDとseedによる再現性を定義する。

## 第3段: 実用的な規模へ

近接粒子リスト、CPU並列化、WebGPU計算を個別に導入する。全粒子対・CPU倍精度の参照実装を残す。

完了条件: 参照実装との誤差を説明でき、粒子数・経路数・実行時間・計算環境をそろえた測定で性能向上を示せること。最適化ごとに数値結果への影響を検証する。

## 第4段: 電子状態へ

空間離散化、固有値計算、Poisson計算、自己無撞着計算を、小さく検証可能な電子系から積み上げる。Electronicは独立した分野モジュールとする。

「現代的な電子状態計算環境」は長期的な製品像であり、WIEN2k互換やAPW+lo実装をv0.1で約束するものではない。手法、基底、境界条件、参照解はこの段階の設計で選ぶ。
